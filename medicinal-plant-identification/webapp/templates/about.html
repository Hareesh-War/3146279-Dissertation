Sequential Transfer Learning Pipeline

The model is trained in 4 phases, each building on the previous:

Phase 1: General Medicinal Features

Dataset 1 — 6 species, 1,380 images. Establishes baseline plant feature recognition.

Phase 2: Regional Context (Bangladesh)

Dataset 2 — 6 species, 1,094 images. Adapts to South Asian regional plant morphology.

Phase 3a: Endangered Species

Dataset 4 (REMP) — 16 species, 3,494 images. Optimized for high recall on endangered species.

Phase 3b: Commercial Species

Dataset 5 (SIMPD) — 20 species, 2,503 images. Optimized for high precision on commercial species.

Independent Test: Dataset 3 (9 species, ~900 images) held out for unbiased evaluation.

🏗️ System Architecture

Frontend: HTML5/JavaScript, mobile-responsive, camera capture API
Backend: Python Flask REST API serving the TensorFlow model
Database: SQLite for species metadata and prediction logging
Model: TensorFlow/Keras, ResNet50 with sequential transfer learning
Training: Google Colab with GPU acceleration

Datasets

All datasets sourced from Mendeley Data:

  • Dataset 1: Indian Medicinal Leaves Dataset (6 species)
  • Dataset 2: Bangladeshi Medicinal Plant Dataset (6 species)
  • Dataset 3: Independent Test Set (9 species) — held for evaluation
  • Dataset 4 (REMP): Rare/Endangered Medicinal Plants (16 species)
  • Dataset 5 (SIMPD): South Indian Medicinal Plants (20 species)

Total: 37 unique species, 9,551 images across 5 datasets
